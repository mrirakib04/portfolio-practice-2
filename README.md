# Portfolio-2: React Portfolio

## Overview

**Portfolio-2** is a responsive and modern React-based personal portfolio website showcasing **Md Rakibul Islam Rakib’s** full-stack software engineering expertise, career milestones, featured production projects, tech arsenal, and contact hub. Designed with a futuristic aesthetic, it delivers an ultra-smooth user experience with glassmorphism, interactive device simulators, responsive layouts, and performant animations.

---

## Features

- **Responsive Design:** Pixel-perfect layout fully optimized for mobile, tablet, laptop, and ultra-wide screens.
- **Header & Navigation:** Sticky glassmorphic navbar with active scroll spy, responsive pill indicator, social shortcuts, and mobile drawer.
- **Hero Section:** Dynamic typewriter role transitions, pulsing status badge, and interactive developer terminal code card.
- **About Bento Section:** Developer journey narrative, real-time Dhaka (UTC+6) live clock widget, and core architectural engineering pillars.
- **Skills Arsenal:** Structured 4-row tech arsenal featuring live search and categorized filter tabs with holographic skill cards.
- **Career Experience Journey:** Commercial agency frontend experience at **Pixelora Studio** and Full Stack Web development with deep-dive interactive modal popups.
- **Featured Projects Showcase:** Full-stack production applications featuring an interactive **Live Device Simulator** (Desktop & Mobile toggle), 1-click credentials copier, live demo, and GitHub links.
- **Education Section:** Academic milestones and business discipline studies shaping analytical problem-solving skills.
- **Contact Hub:** Direct messaging form powered by **EmailJS**, 1-click email copy button, and social channels.
- **Animations & Visuals:** Ultra-smooth transitions using **Framer Motion**, **AOS (Animate on Scroll)**, multi-layered aurora ambient glow, and top scroll progress indicator.
- **Resume Download:** Instant 1-click direct download popup for the latest Resume (CV).

---

## Technologies Used

- **Frontend:** React 19, Vite, Tailwind CSS v4, Material UI (MUI)
- **Animations:** Framer Motion, AOS (Animate on Scroll)
- **Icons:** Lucide React, Custom SVG Icons
- **Communication:** EmailJS
- **Hosting & Deployment:** Netlify (Live demo link provided below)
