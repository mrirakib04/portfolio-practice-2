# Portfolio: React Personal Portfolio

## Overview

**MRI Rakib Portfolio** is a high-performance, modern personal portfolio website showcasing **Md Rakibul Islam Rakib’s** full-stack software engineering expertise, professional career journey, featured production projects, skills arsenal, and academic background. Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**, it delivers an ultra-smooth, futuristic user experience with interactive device simulators, glassmorphic UI, and responsive design across all devices.

---

## 🌟 Key Features

- **Responsive & Modern Design:** Pixel-perfect layout fully optimized for mobile, tablet, laptop, and ultra-wide screens.
- **Top Navigation Bar:** Sticky glassmorphic navbar with active scroll spy, responsive menu pill, social links, and mobile drawer.
- **Dynamic Hero Section:** Typewriter role animations, interactive developer terminal code card, pulsing status badge, and floating experience widgets.
- **Bento About Section:** Developer journey, real-time Dhaka (GMT+6) live clock widget, headquarters details, and core architectural engineering pillars.
- **Tech Arsenal (Skills):** Categorized holographic skill cards with instant live search bar and filter tabs (Languages, Frontend, Backend, Database, State Management, E-Commerce, Design Tools).
- **Career Experience Journey:** Commercial agency experience at **Pixelora Studio** (*Jr. Frontend Developer - Shopify & Liquid*) and **Full Stack Web Engineering** with interactive **"View Details & Key Work"** popup modal.
- **Featured Projects Showcase:** Full-stack production applications featuring:
  - Interactive **Live Device Simulator** (with Desktop 💻 & Mobile 📱 responsive viewport toggle).
  - High-resolution landing showcase.
  - 1-Click demo login credentials copying.
  - Direct live demo, client repository, and backend server repository links.
  - Deep-dive project specification modal popup.
- **Education & Academic Background:** Academic qualifications including Higher Secondary Certificate (HSC - 1st Year) at Sataish School & College and Secondary School Certificate (SSC - GPA 3.39) at Language High School.
- **Contact Hub:** Direct messaging form, 1-click email copy button, response time metrics, and social profiles.
- **Smooth Animations & Visuals:** Powered by **Framer Motion**, **AOS (Animate on Scroll)**, glowing multi-layer ambient background aura, and top scroll progress indicator.

---

## 🛠️ Technologies Used

- **Core & Framework:** React 19, Vite
- **Styling & Design System:** Tailwind CSS v4, Vanilla CSS, Material UI (MUI)
- **Animations:** Framer Motion, AOS (Animate on Scroll)
- **Icons:** Lucide React, Custom SVG Icons
- **E-Commerce & Liquid:** Shopify Theme Architecture, Custom Liquid
- **Hosting & Deployment:** Netlify
